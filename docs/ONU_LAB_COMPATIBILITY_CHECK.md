# ONU 现场只读兼容性检查使用说明

## 1. 用途

本入口用于在正式运行“ONU 注册与双 WAN 联网验证 Skill”之前，检查测试电脑、Huawei MA5800-X7、ONU Web 页面和证据保存能力是否适配当前 Workbench。

现场兼容性检查不会注册或删除 ONU，不会下发或删除 WAN，不会修改 service-port，
不会执行 ONU Web Ping，也不会把检查结果写成产品 PASS/FAIL。

检查只产生 `READY`、`PARTIAL` 或 `BLOCKED` 兼容性结论，不创建正式 TestRun、Result、Defect、回归或报告归档记录。

## 2. 开始前准备

请先确认：

- 测试电脑能够访问 OLT 管理网和 ONU 本地管理地址。
- Workbench 后端仅绑定 `127.0.0.1`、`::1` 或 `localhost`。
- OLT 是首版支持的 Huawei MA5800-X7。
- ONU Web 当前使用 `neutral-v1` 页面适配器。
- 测试电脑已经连接需要验证的 ONU LAN 或 Wi-Fi 网卡。
- 不要在输入框、截图名称或凭据引用中填写真实密码。

## 3. 需要填写的参数

### OLT

- OLT 私有 IP 地址和 SSH 端口。
- 页面读取到的 SSH 主机指纹。测试人员必须与已知设备指纹核对后勾选确认。
- OLT 用户名凭据引用和密码凭据引用，例如公司内部约定的本机引用名称。
- 可选 ONU SN，格式为 16 位十六进制字符。
- 可选 Frame、Slot、PON 端口和 ONT ID。这四项必须同时填写或全部留空。

### ONU Web

- 本地管理地址，只允许私有、链路本地或回环 IP 的 HTTP/HTTPS 地址。
- ONU Web 用户名凭据引用和密码凭据引用。
- 首版适配器 `neutral-v1`。

### 测试电脑

- Windows 中显示的网卡名称。
- 该网卡当前使用的本地源 IP 地址。
- Ping 目标。离线实验室可以填写内网目标；需要公网验证时由测试人员明确填写公网目标。

## 4. 凭据处理

四项秘密分别写入 Windows 本机凭据保险箱：

- OLT 用户名。
- OLT 密码。
- ONU Web 用户名。
- ONU Web 密码。

数据库、检查报告、日志和 API 响应只保存凭据引用，不保存秘密值。页面完成保存后会清空秘密输入框。

## 5. 操作步骤

1. 打开 Workbench，选择“现场检查”。
2. 在“填写目标”中填写现场参数。
3. 点击“读取主机指纹”，与已知 MA5800-X7 指纹核对。
4. 指纹一致后勾选“我已核对 OLT 主机指纹”。如果指纹变化，停止操作并核对所连接设备。
5. 在“检查凭据”中先点击“检查已有凭据”；仅对本机未找到的项目输入秘密并保存。
6. 点击“开始只读检查”。运行期间不要重复点击。
7. 查看八个阶段的状态、中文处理建议和证据 SHA256。
8. 与负责人共同确认总体状态，再决定是否进入正式 Skill。

## 6. 状态说明

### 阶段状态

- `已验证`：该能力在当前现场可用。
- `需补充`：缺少定位参数、连接或其他人工输入。
- `受阻`：连接、安全校验、解析器、页面适配或 Ping 无法可靠完成。
- `未执行`：前置阶段尚未满足，因此没有执行。

### 总体状态

- `READY`：所有阶段均已验证，可以准备正式 Skill 验证。
- `PARTIAL`：基础只读能力可用，但缺少当前 ONU 注册/WAN 状态等信息；需要人工确认是否补充后重跑。
- `BLOCKED`：关键能力受阻，不允许据此进入配置变更阶段。

以上状态都不是 ONU 产品质量结论。

## 7. 常见处理建议

- 主机指纹未知：读取后通过 OLT 管理负责人或可信记录核对，不要直接确认陌生指纹。
- 主机指纹变化：停止连接，检查 IP 是否指向错误设备或设备密钥是否发生计划外变化。
- 凭据不存在：在“检查凭据”中重新保存对应秘密。
- SN 未发现：核对供电、光纤、PON 口、SN 和自动发现状态。
- 尚无 WAN：兼容性报告可以是 `PARTIAL`，不能据此判断 ONU 功能失败。
- ONU Web 登录失败：核对管理地址、账号、密码和当前产品固件。
- 页面选择器不兼容：保留脱敏页面证据，用真实页面结构增加产品适配器测试。
- 指定网卡不可用：确认网卡名称、连接状态和源地址后重试。
- Ping 输出无法识别：确认系统使用 Windows Ping，并保留控制台证据用于解析器校准。
- 证据目录不可写：检查本地数据目录权限和磁盘空间。

## 8. 证据位置与内容

默认检查数据保存在配置项 `TEST_WORKBENCH_LAB_COMPATIBILITY_ROOT` 指向的目录；默认值为：

```text
./data/runner-evidence/lab-compatibility/<check-id>/
```

每次检查包含：

- `report.json`：参数引用快照、阶段状态和相对证据路径。
- OLT 查询的脱敏文本与终端 PNG。
- ONU Web WAN 页面和 Ping 页面脱敏文本与截图。
- 电脑侧 Ping 文本与终端 PNG。
- 每个证据文件的 SHA256 和大小。

报告不得出现秘密、任意命令正文、未脱敏页面内容或本机绝对存储路径。

## 9. 重试与后续

- 修正现场参数或连接后，可以创建新的只读检查。
- 同一时间只允许一个检查运行，避免重复连接设备。
- `READY` 或经负责人接受的 `PARTIAL` 报告必须先经过人工复核。
- 未经用户确认，不得继续正式 Skill 的 ONU 注册、删除、WAN 下发或恢复动作。
- 离线安装和桌面双击启动由正式 Skill 主计划的离线打包任务统一交付，本入口不提供第二套安装器。
